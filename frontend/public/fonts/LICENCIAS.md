# Fuentes tipográficas

Archivos `woff2` variables, subconjunto latino (U+0000–00FF y signos comunes; cubre
español). Descargados de Google Fonts el 2026-10-21 y alojados localmente para no
depender de servicios externos en tiempo de ejecución.

| Archivo                    | Familia           | Uso                                            | Licencia                  |
| -------------------------- | ----------------- | ---------------------------------------------- | ------------------------- |
| `manrope-latin-wght.woff2` | Manrope (200–800) | Titulares, navegación, elementos destacados    | SIL Open Font License 1.1 |
| `inter-latin-wght.woff2`   | Inter (100–900)   | Texto y controles de interfaz                  | SIL Open Font License 1.1 |
| `caveat-latin-wght.woff2`  | Caveat (400–700)  | Titulares expresivos y anotaciones manuscritas | SIL Open Font License 1.1 |
